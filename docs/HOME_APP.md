# Titan Home — киоск самообслуживания на Android-планшете

Нативное приложение для планшета в кабинке: гость видит действующий счёт, заказывает из меню, пишет администратору, платит по QR СБП с чаевыми, оценивает вечер и сам управляет светом и кондиционером кабинки (Home Assistant). Expo SDK 57 (React Native 0.86), без WebView. Веб-версия `/tablet` остаётся как запасной вариант.

- **Код:** `apps/home` (свой `npm`, исключён из pnpm-воркспейса и Docker-контекста)
- **Android:** пакет `ru.titan.home`, только Android (`platforms: ["android"]`)
- **Сервер:** клуб по поддомену, как в Titan HUB (`kbr` → `kbr.titanpos.ru`)
- **Сборка:** `npm run android:device` (Release APK, подпись debug-ключом — для своих планшетов), `EXPO_PUBLIC_LOCAL_STACK=1` — сборка для локального стенда

## Экраны

| Экран | Что делает |
| --- | --- |
| `setup` | Первая настройка сотрудником: адрес клуба → кабинка → PIN сотрудника. Если сессия истекла — сразу PIN |
| `index` — главный | Действующий счёт (итог с живой арендой, заказы на подтверждении, позиции) или «Счёт ещё не открыт»; кнопка «Меню»; «Позвать», «Чат», «Попросить счёт», «Оплатить». После закрытия счёта — «Спасибо» и оценка вечера |
| `menu` | Меню без фото: категории, текстовые плитки с ценой и +/−, корзина, поиск. Без открытого счёта — только просмотр |
| `chat` | Чат с администратором, быстрые фразы; ответы приходят по SSE |
| `pay` | Чаевые 0/5/10/15 % → QR СБП; оплату подтверждает вебхук банка, планшет узнаёт по SSE |
| `staff` | Панель сотрудника (удержать логотип 2 с → PIN): режим киоска, ориентация, свет и климат, Wi-Fi/настройки Android, смена кабинки/клуба |
| `staff/room` | Выбор устройств Home Assistant для кабинки: до двух групп света и кондиционер, подписи для гостя |

Панель **«Свет и климат»** видна на всех экранах гостя: справа в альбомной ориентации, снизу в книжной (снизу прячется, пока открыта клавиатура). Свет — только вкл/выкл; кондиционер — питание, температура ± (шаг из HA, отправка одной командой после паузы), режимы и скорость обдува.

## Визит гостя

1. Планшет раз в 4 с спрашивает открытый счёт своей зоны (`GET /pos/checks` — сервер сам ограничивает tablet-токен зоной).
2. Администратор открыл счёт в кассе → главный экран показывает его; живые события чека — SSE `GET /pos/checks/:id/events` (Bearer).
3. Счёт пропал из открытых → приложение проверяет сам чек: `closed` → «Оплата прошла!/Счёт закрыт» и оценка; `cancelled` или чек переехал в другую зону → просто снова «Счёт ещё не открыт».
4. После оценки (или минуты без касаний) — снова главный экран. **Сессия планшета не сбрасывается**: следующему гостю PIN сотрудника не нужен (в веб-киоске `/tablet` после каждого счёта был выход).
5. Гость ушёл посреди меню/чата — через 2 минуты без касаний киоск возвращается на главный экран и очищает корзину.

Сессия скользящая: раз в 3 дня `POST /auth/tablet-refresh` меняет tablet-токен на свежий (30 дней). Если tablet-профиль зоны удалён или зона выключена — 401, и планшет просит PIN сотрудника.

## Режим киоска

Нативный модуль `modules/titan-kiosk` (Kotlin):

| Уровень | Что даёт | Как включить |
| --- | --- | --- |
| Обычный | Полный экран, экран не гаснет, кнопка «Назад» не выпускает из приложения, Titan Home можно выбрать «домашним экраном» | Сразу после установки; «Домой» → выбрать Titan Home → «Всегда» |
| Закрепление экрана | Гость не выйдет кнопками «Домой»/«Недавние» | Панель сотрудника → «Закрепить экран» (Android спросит подтверждение) |
| **Владелец устройства** (рекомендуется) | Закрепление без вопросов при каждом запуске, «Домой» навсегда = Titan Home, шторка уведомлений и экран блокировки отключены, экран не гаснет на зарядке, перезагрузка из панели | Один раз на сброшенном планшете без аккаунтов: `npm run kiosk:owner` (= `adb shell dpm set-device-owner ru.titan.home/expo.modules.titankiosk.KioskAdminReceiver`) |

Вернуть планшет в обычный режим: панель сотрудника → «Снять режим владельца устройства» (только после этого Titan Home можно удалить).

Ориентация по умолчанию — «Как планшет»: на больших экранах Android не поворачивает дисплей под приложение, а сужает его полосой, поэтому фиксировать альбомную/книжную стоит, только если планшет так и стоит. Поворот закрепляют в настройках Android.

## Home Assistant

- Планшет и Home Assistant — в одной сети клуба; планшет ходит к HA **напрямую** по WebSocket API (`ws://<ha>:8123/api/websocket`). Сервер Titan в локальную сеть не ходит. Для `http://` в приложении разрешён незашифрованный трафик (`usesCleartextTraffic`).
- Адрес и токен — интеграция клуба «Home Assistant» в Titan HUB: «Управление» → «Настройки» → «Интеграции» (ключи `ha_url`, `ha_token`, хранятся зашифрованно). Планшет получает их `GET /pos/tablet/smart-home` — это осознанное исключение из правила «секреты не покидают сервер». **Создайте в HA отдельного пользователя без прав администратора** и выпустите долгосрочный токен от его имени.
- Устройства кабинки выбирает сотрудник на самом планшете (`staff/room`, список из HA `get_states`): до двух сущностей `light.*`/`switch.*`/`input_boolean.*` и одна `climate.*`. Сохраняется в зоне: `spaces.smart_home`, `PUT /pos/tablet/smart-home` (только своя зона).
- Состояния — подписка `subscribe_entities` (плитка переключится, даже если свет щёлкнули выключателем). Команды: `light|switch|input_boolean.turn_on/turn_off`, `climate.set_hvac_mode`, `climate.set_temperature`, `climate.set_fan_mode`; на экране — сразу, с откатом при ошибке. Обрыв — переподключение 1→30 с, ping раз в 30 с; неверный токен — без повторов, статус «Нет доступа».
- Опция панели сотрудника «Выключать после счёта»: когда счёт закрыт, планшет гасит свет и выключает кондиционер.

## Оценка вечера

`POST /pos/checks/:id/feedback {rating 1–5, tags[], comment?}` — только закрытый чек своей зоны, в течение 6 часов после закрытия; повторная отправка перезаписывает (`guest_feedback`, уникальный `check_id`). Оценка ≤ 3★ или с комментарием → уведомление персоналу типа `guest_feedback` (отключается в настройках уведомлений). Владелец видит отзывы в аналитике: вкладка «Отзывы» (`GET /analytics/feedback?from&to` — средняя, распределение, теги, лента).

## Серверные изменения (миграция 065)

- `guest_feedback` — оценки; `spaces.smart_home jsonb` — устройства Home Assistant зоны.
- `POST /auth/tablet-refresh`, `GET/PUT /pos/tablet/smart-home`, `POST /pos/checks/:id/feedback`, `GET /analytics/feedback`.
- Интеграции `ha_url`, `ha_token`; тип уведомления `guest_feedback`.

## Проверка на стенде

Локальный стенд: Postgres 16 + API из `apps/api/dist` на `:3901` + Redis (fakeredis с командой `INFO`) + имитатор Home Assistant (WebSocket на `:8123`). Сборка `EXPO_PUBLIC_LOCAL_STACK=1`, адрес клуба в приложении — `10.0.2.2:3901` для эмулятора или `192.168.x.x:3901` для планшета в Wi-Fi.
