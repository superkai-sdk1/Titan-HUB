## Спринт 0 — разблокировка SaaS (3×P0)

| P0 | Проблема | Решение |
|---|---|---|
| #1 Схема клуба | Новый клуб поднимался с неполной схемой (baseline пропускал 050,053–059, но помечал применёнными); существующие клубы не получали миграций | `runMigrationsOn(db)` применим к любой клуб-БД; провижининг сеет только `BASELINE_MIGRATIONS` (51 файл) и доприменяет остаток раннером; старт мигрирует все клуб-БД; 2 страховки от рассинхрона + новый `baseline-manifest.ts` |
| #2 Утечка между клубами | JWT/SSE-тикет без клуба, тенант только по Host → owner клуба A читал поток клуба B | `clubId` в JWT и SSE-тикете; `requireAuth` сверяет с клубом домена (SSE строго, Bearer с грейсом для легаси) |
| #3 Вебхук Platega | Писал в дефолтную БД + стоял за гейтом подписки → платежи арендаторов терялись, «гость заплатил — чек не закрылся» | Вебхук поднят до гейтов; клуб резолвится из payload `club:<clubId>:<id>` (`getClubDbById`); resident-payload тоже привязан к клубу |

## Спринт 2 — апгрейды клиента и фронта (4 агента)

**Клиентский сервис Titan Resident:**
- **Service Worker** (был его полный отсутствие) — офлайн-оболочка, network-only для `/api/*`, управляемое
  обновление, **заготовки push-обработчиков** (push/notificationclick) → готов к Web Push без правок SW.
- **Logout** в Профиле (зовёт серверный `/auth/logout` + чистит токен) — закрыл 30-дневный сеанс на общем устройстве.
- **Фикс оплаты** — синхронное открытие окна банка (обход popup-блокера iOS), кнопка «Отменить», честный таймаут.
- **Accessibility** — `aria-current`, `role=dialog`+focus-trap+Esc, `prefers-reduced-motion`, контраст до AA.
- **Поллинг** сведён в один (был двойной), останавливается при `document.hidden`. *(resident-SSE нет — поток
  закрыт `requireRole('owner','staff')`; новый эндпоинт не городили, это бэкенд-скоуп.)*
- **Декомпозиция** (консервативно): вынесены styles, money-хуки, `BalanceCard`/`FeedRow`/`BottomNav`.
- **manifest.json** доведён под установку на iPhone (maskable-иконки, scope/start_url с basePath).

**Админка/POS apps/web:**
- **Управляемое обновление PWA** — убран безусловный `skipWaiting()` (ронял открытую кассу ChunkLoadError'ом);
  теперь плашка «Обновить» → `SKIP_WAITING` → `controllerchange` → reload. `CACHE_VERSION` v283→v284.
- **SSE-реконнект** с экспоненциальным бэкоффом + джиттером, новый тикет на каждый реконнект, форс при
  `visibilitychange`/`online` (лечит молчаливый обрыв после блокировки экрана iPhone).
- **Route error boundaries** — `app/error.tsx` + pos/dashboard/manage; детект ChunkLoadError → «Обновить»;
  больше не выкидывает из активного чека. Новая `app/offline/page.tsx`.
- **Render-blocking шрифт** — удалён неиспользуемый Material Symbols (иконки — инлайн-SVG); Inter/JetBrains
  переведены на non-render-blocking загрузку → выигрыш LCP.

## Перед деплоем — обязательная проверка

1. **Дубли для миграции 060:** unique-индекс упадёт при исторических дублях. Прогнать:
   `SELECT platega_tx_id,count(*) FROM checks WHERE platega_tx_id IS NOT NULL GROUP BY 1 HAVING count(*)>1;`
   и аналогично `resident_payments(provider,transaction_id)`. Если есть — почистить до деплоя.
2. **Бэкап control- и club-БД** перед первым деплоем со спринтами (старт применит 050,053–059 ко всем клубам).
3. **iPhone-проверка** клиентского сервиса после деплоя: установка PWA, офлайн, оплата (popup-поведение), logout.
4. **Бамп SW**: web уже v284; при следующих фронт-правках бампить снова.
