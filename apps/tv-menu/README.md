# Titan Menu — приложение для ТВ-приставки

Отдельное Android-приложение (не Titan Home и не экран кабинки): показывает меню клуба
`https://<клуб>.titanpos.ru/menu` (страница `apps/web/public/tv-menu.html`) на весь экран
телевизора через приставку. Цены, темы и реклама по-прежнему настраиваются в Titan HUB.

- Android 7.1+ (рекомендуем приставку на Android 10+), пакет `ru.titan.menu`.
- Нативный Kotlin без библиотек, один WebView; APK ~80 КБ.
- Поворот под вертикальный телевизор делает само приложение (`RotatedLayout`): приставка
  отдаёт горизонтальный HDMI, страница видит обычный вертикальный экран.
- Нет связи / сервер перезапускается — заставка со статусом и повтор (5 → 60 с), при появлении
  сети — сразу. Упал процесс страницы — WebView пересоздаётся.
- Экран не гаснет, «Назад» меню не закрывает. Настройки — удерживать OK или кнопка «Меню».

## Сборка

```bash
cd apps/tv-menu
echo "sdk.dir=$HOME/Library/Android/sdk" > local.properties
./gradlew assembleRelease   # → app/build/outputs/apk/release/app-release.apk
```

Подпись — ключ вне репозитория: `~/.titan-keys/titan-menu.jks` и `titan-menu.properties`
(`storeFile`, `storePassword`, `keyAlias`, `keyPassword`). Без него релиз подписывается
отладочным ключом, и такое обновление поверх установленного приложения не встанет.
Новая версия — поднять `versionCode` в `app/build.gradle.kts`.

## Установка на приставку

- Флешка: скопировать APK, открыть файловым менеджером приставки, разрешить установку
  из неизвестных источников.
- По сети: `adb connect <ip-приставки>` и `adb install -r app-release.apk`.

## Первая настройка (пультом)

1. Адрес клуба (по умолчанию `kbr.titanpos.ru`) и как висит телевизор.
2. «Запустить меню». Если меню на боку или вверх ногами — удерживать OK → другой поворот.
3. Автозапуск после включения: на Android 10+ нужно разрешение «Поверх других приложений»
   (кнопка в настройках) или «Сделать главным экраном». Если такого экрана в прошивке нет:
   `adb shell appops set ru.titan.menu SYSTEM_ALERT_WINDOW allow`.

## Проверка без приставки

Эмулятор 1920×1080, 320 dpi (профиль `tv_1080p`). Адрес `http://10.0.2.2:<порт>/menu` —
локальный сервер разработчика (HTTP разрешён только для `10.0.2.2` и `localhost`).
Страницу внутри приложения можно отлаживать через `chrome://inspect`.
